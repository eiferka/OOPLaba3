# Лабораторная работа 3

## Тема

Разработка Web API на C# с реализацией CRUD-операций и связями между таблицами в базе данных.

## Описание проекта

Проект представляет собой ASP.NET Core Web API для работы с учебными данными.

В системе реализованы следующие сущности:

- Groups — учебные группы
- Students — студенты
- Courses — курсы
- Enrollments — записи студентов на курсы

## Используемые технологии

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- Swagger

## Структура базы данных

### Groups

Таблица учебных групп.

Поля:

- Id — уникальный идентификатор группы
- Direction — направление подготовки
- AdmissionYear — год поступления
- Name — название группы

### Students

Таблица студентов.

Поля:

- Id — уникальный идентификатор студента
- FullName — ФИО студента
- Age — возраст студента
- GroupId — идентификатор группы, в которой учится студент

### Courses

Таблица курсов.

Поля:

- Id — уникальный идентификатор курса
- Title — название курса
- Hours — количество часов курса

### Enrollments

Таблица записей студентов на курсы.

Поля:

- Id — уникальный идентификатор записи
- StudentId — идентификатор студента
- CourseId — идентификатор курса
- EnrollmentDate — дата записи студента на курс
